# Sahar Mirzazadeh — Portfolio

A bilingual English–Korean portfolio that brings together my frontend, data, and computer science projects in one focused story.

## Live site

[sahar-portfolio-taupe.vercel.app](https://sahar-portfolio-taupe.vercel.app)

## Highlights

- English and Korean content with a remembered language preference
- A compact interactive 3D room built with React Three Fiber
- A CSS illustration fallback for mobile devices and browsers without WebGL
- Real project case studies with verified source and live links
- Reduced-motion support and semantic, responsive navigation
- Light pastel glass interface designed specifically for this portfolio

## Featured work

- **KNU StudySpot Intelligence (LXP)** — campus study-space discovery and comparison
- **ML Stock Backtest** — Naver Finance data, Random Forest modelling, and backtesting
- **Dynamic Hash Table** — a C implementation with automatic resizing
- **Bilingual 3D Portfolio** — this Next.js and WebGL experience

## Tech stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS 4
- React Three Fiber / Three.js
- Vercel Analytics

## Run locally

```bash
pnpm install
pnpm dev
```

Then open [http://localhost:3000](http://localhost:3000).

## Quality checks

```bash
pnpm lint
```
